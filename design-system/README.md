# LDERLY Design System

LDERLY's interface is optimized for calm healthcare operations: realtime status, family reassurance, and fast operational scanning.

## Foundations

- Typography: clear, high-confidence headings with readable body text.
- Color: deep slate/ink base, muted emerald for healthy states, indigo for intelligence, amber for watch, rose for emergency only.
- Motion: short micro interactions, calm panel transitions, urgent spring motion only for emergency states.
- Surfaces: restrained glass for live overlays and operational panels, warm cards for family trust moments.

## Component Principles

- One primary action per screen.
- Live state should be visible without visual noise.
- Trust signals should be close to the decision point.
- Empty states should explain what the system is doing next.
